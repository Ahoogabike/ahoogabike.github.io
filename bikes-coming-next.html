Serial number rule

Serial prefixes are pre-filled to match the Production Planner (Yellow→MAYA, Black→MABS, Red→MARA, Custom→MACU). The next number is taken automatically from the highest existing MA… serial of that prefix in Odoo, +1, padded to 7 digits — no setup needed. Change a prefix only if the planner's rule changes; it saves to the shared cloud store.

e.g. 7 → MARA0000592
